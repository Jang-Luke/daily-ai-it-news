# 2026-11-22 AI·IT 개발 뉴스

최근 24시간의 공식 발표·릴리스와 공개 기술 토론을 우선해 같은 사건을 합쳤습니다. 공급자 성능 수치와 preview 기능은 독립 검증 또는 안정판과 구분했습니다.

## AI Agent·개발 도구

### AWS Quick, agent·skill·connector·flow를 묶는 plugin 지원

AWS Quick가 특정 업무에 필요한 agent, skill, connector와 flow를 한 번에 설치·공유하는 plugin 단위를 공개했습니다. AWS가 제공하는 100개 이상의 skill·plugin 외에도 사용자가 chat으로 업무를 설명해 조직용 plugin을 조립할 수 있습니다.

- **중요한 이유:** 기업용 agent 배포 단위가 표준화되지만 connector 권한, plugin 공급망과 공유 범위를 검토하고 설치 전 최소권한·승인 절차를 둬야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-quick-plugins-bundle-agents-skills-connectors-flows/)

### AWS Quick Flows, 대화형 장기 실행 자동화 강화

Quick Flows가 chat으로 flow를 만들고 agent·skill·tool, 구조화 데이터와 업무 앱을 orchestration하도록 확장됐습니다. deterministic step과 단계별 validation을 추가했고 desktop·web·mobile에서 실행하며 local file과 browser 작업도 다룰 수 있습니다.

- **중요한 이유:** invoice·purchase order 대조 같은 업무를 빠르게 자동화할 수 있지만 agent 판단과 deterministic 검증을 분리하고 중복 지급, 장기 실행 timeout과 사람 승인 경계를 설계해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-quick-flows-automations-chat/)

### Bedrock Web Search, 일본어 등 5개 언어와 국가 편향 검색 지원

Amazon Bedrock와 AgentCore의 Web Search가 일본어·독일어·프랑스어·스페인어·이탈리아어 및 비미국 영어를 지원합니다. ISO 국가 코드를 선택적으로 넘겨 지역 규정·가격·공직자처럼 위치 의존적인 질의에서 해당 국가 자료를 우선할 수 있습니다.

- **중요한 이유:** 다국어 RAG의 지역 적합성이 높아지지만 국가 편향은 사실 검증을 대신하지 않으므로 인용 출처의 날짜·관할·다양성을 별도로 검사해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/web-search-amazon-bedrock/)

## 보안·클라우드·플랫폼

### GPGME 2.3.1, critical double-free 취약점 수정

GnuPG 프로젝트가 조작된 매우 긴 OpenPGP user ID로 double free를 유발하는 CVE-2026-129975를 공개하고 GPGME 2.3.1로 즉시 업데이트하라고 권고했습니다. 데이터 유출이 가능하고 RCE 가능성도 배제하지 않았으며 Gpg4win, mail·XMPP client, Samba와 Flatpak 등 이전 GPGME를 쓰는 software가 영향권입니다.

- **중요한 이유:** shared library뿐 아니라 정적 링크 binary도 재빌드해야 합니다. 자산에서 GPGME 의존성을 찾아 2.3.1 적용 여부를 확인하고 서명된 비신뢰 key·message 처리 경로를 우선 차단·점검해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [GnuPG Security Advisory](https://lists.gnupg.org/pipermail/gnupg-announce/2026q4/000517.html)

### AWS Network Firewall automated Internet firewall preview

AWS가 VPC 내부의 전용 subnet·route 변경 없이 Internet Gateway에서 inbound·outbound traffic을 중앙 검사하고 NAT·logging까지 제공하는 자동화 모드를 public preview로 공개했습니다. account·organization·OU 범위와 향후 생성되는 VPC까지 정책을 확장할 수 있습니다.

- **중요한 이유:** 우회 경로와 운영 복잡성을 줄일 수 있지만 preview의 장애 반경이 크므로 작은 VPC에서 egress·return path, NAT 비용, 예외·rollback과 중앙 정책 오배포를 검증해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/network-firewall-automated-internet/)

### CloudWatch Omni, Azure log·metric·trace 수집 지원

CloudWatch Omni가 Azure resource log, Azure Monitor platform metric, VNet flow log와 Application Insights trace를 AWS telemetry와 함께 수집합니다. Microsoft Entra ID tenant를 연결하고 subscription·region·resource type·tag별 범위를 고를 수 있습니다.

- **중요한 이유:** AWS↔Azure 분산 trace를 한 화면에서 볼 수 있지만 cross-cloud IAM, 데이터 전송·수집 비용, 지역 규제와 high-cardinality label을 먼저 통제해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-cloudwatch-omni-microsoft-azure)

### Cognito multi-Region replication 지원 지역 확대

Cognito MRR가 사용자·machine identity credential, user-pool 설정과 federation 구성을 지정한 standby Region에 near-real-time으로 복제하는 지원 지역을 확대했습니다. Essentials·Plus plan의 add-on이며 multi-Region KMS customer-managed key가 필요합니다.

- **중요한 이유:** 인증 region 장애 대응이 쉬워지지만 credential 복제의 데이터 주권, KMS key 운영, DNS·application failover와 write conflict를 실제 DR 훈련에서 확인해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/cognito-mrr-opt-in-regions/)

## 데이터베이스·관측성

### RDS for Oracle Primary Endpoint 제공

RDS for Oracle Enterprise Edition이 replica switchover 뒤에도 현재 primary를 가리키는 DNS Primary Endpoint를 추가 비용 없이 제공합니다. 기존 instance endpoint는 유지되며 같은 Region과 cross-Region replica 전환에서 application connection string 변경을 줄입니다.

- **중요한 이유:** DR 전환 자동화는 단순해지지만 DNS TTL, 기존 connection pool의 stale session, transaction replay와 client reconnect 동작을 별도로 시험해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-primary-endpoint-v2/)

### RDS for Oracle Replica First Patching 지원

Oracle Enterprise Edition replica에 minor version을 먼저 적용해 read traffic으로 검증한 뒤 정한 window 안에서 primary로 전환할 수 있습니다. 전환하지 않으면 replica를 원래 version으로 되돌리고, 전환 후 나머지 replica와 이전 primary를 같은 version으로 올립니다.

- **중요한 이유:** upgrade downtime을 줄이지만 read-only 검증만으로 write workload를 보장하지 않으므로 query plan, driver와 transaction 회귀를 staging·canary에서 확인해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-replica-first-patching/)

### Neptune Serverless, Graviton4와 scaling 개선

새 Neptune Serverless instance가 Graviton4에서 실행되며 AWS는 같은 NCU 가격에서 최대 30% 성능 개선을 주장했습니다. concurrent graph query가 많은 fraud detection·recommendation·generative AI lookup을 겨냥해 scaling algorithm도 조정됐습니다.

- **중요한 이유:** graph workload의 비용·지연 개선 가능성이 있지만 공급자 최대치는 query mix별로 다르므로 p95 latency, scale-up 시간과 cold cache를 자체 benchmark해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-neptune-serverless-r8g-generally-available)

### CloudWatch PromQL query window 30일로 확대

OpenTelemetry metric 대상 PromQL query window가 7일에서 30일로 늘었습니다. 한 query로 30일 rolling SLO, error budget과 월·주간 추세를 계산하고 장기 baseline alarm을 구성할 수 있습니다.

- **중요한 이유:** SLO 계산 파이프라인이 단순해지지만 30일 query의 scan 비용·dashboard latency와 metric retention·cardinality를 함께 측정해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/cloudwatch-promql-query-30days/)

### S3 Vectors, filterable metadata를 vector당 40KB로 확대

S3 Vectors가 vector당 filter 가능한 metadata 한도를 2KB에서 40KB로 높였습니다. 새 vector bucket index는 기본 적용되고 기존 index는 UpdateIndexMode API로 enhanced mode로 바꿔야 합니다.

- **중요한 이유:** 상품 category·권한·timestamp를 더 풍부하게 pre-filter할 수 있지만 metadata 중복 저장, 권한 필터 누락과 index-mode migration 성능을 검증해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-s3-vectors-raises-filterable-metadata-40kb-per-vector/)

## 아키텍처·커머스·주문 처리

### Lambda, Event Function 상태 변경을 EventBridge로 발행

Lambda가 function version 생성·갱신·publish·삭제에 따른 상태 변경 event를 EventBridge로 자동 발행합니다. deployment pipeline이 GetFunction polling 없이 active·failed 상태를 받아 integration test나 alias traffic 전환을 시작할 수 있습니다.

- **중요한 이유:** serverless 배포 orchestration이 단순해지지만 event의 중복·순서 역전을 전제로 version ARN과 상태를 확인하고 idempotent target을 구성해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-function-state-events/)

### Lambda SQS FIFO batch, provisioned mode에서 최대 10,000개

SQS FIFO event source mapping의 provisioned mode가 batch size를 기존 10개에서 최대 10,000개, batching window를 최대 300초까지 지원합니다. message group 내부 순서를 유지하면서 금융 transaction·주문·재고 event를 더 적은 invocation으로 처리할 수 있습니다.

- **중요한 이유:** 처리량과 비용은 개선될 수 있지만 대형 batch의 실패 재처리, visibility timeout, partial response, poison message와 최대 허용 지연을 부하 시험해야 합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-lambda-10K-batch-size-SQSFIFO/)

### Glue Data Catalog, catalog·database 단위 품질 감시

Glue Data Quality가 catalog나 database에 한 번 정의한 profiling·DQDL 규칙을 현재와 이후 추가되는 모든 table에 일정 또는 metadata 변경 시 적용합니다. 세 번 실행 뒤에는 규칙 밖의 통계 drift도 탐지하고 결과를 API, Iceberg table 또는 S3에 저장할 수 있습니다.

- **중요한 이유:** 주문·정산 pipeline의 schema·품질 감시 누락을 줄이지만 Iceberg commit마다 실행할 때 비용·지연이 커질 수 있어 critical table별 SLA와 quarantine 정책이 필요합니다.
- **발표일:** 2026-11-21 KST
- **원문:** [AWS](https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-data-quality-monitoring/)

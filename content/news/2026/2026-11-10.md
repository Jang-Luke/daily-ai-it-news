Google은 차세대 TPU 8i Max와 8TX 및 이를 뒷받침하는 글로벌 네트워크 구성을 발표했습니다. 세부 성능·가격은 워크로드와 제공 리전에 따라 달라지므로 공급자 수치만으로 GPU 대체 효과를 단정하기보다 실제 모델의 학습·추론 benchmark가 필요합니다.

## 보안·플랫폼

### Home Assistant 장기 bearer token 보관·폐기 방식에 문제 제기

한 보안 연구자가 Home Assistant의 bearer token이 평문으로 보관되고 password 변경만으로 기존 token이 폐기되지 않는다고 보고했습니다. 이는 독립 연구자의 공개 분석이며 영향 범위와 수정 상태는 프로젝트의 공식 advisory·issue에서 추가 확인해야 합니다.

- **중요한 이유:** IoT·agent integration token은 장기 secret으로 취급해 저장 암호화, device별 revoke, rotation과 탈취 탐지를 갖춰야 합니다.
- **공개일:** 2026-11-09
- **원문:** [Garrett Stimpson — Home Assistant token custody](https://garrettstimpson.ca/posts/2026/11/08/home-assistant-not-the-key-token-custody/)

### Stack Overflow, password 공유를 없애는 OAuth 2.0 실무 해설 공개

Stack Overflow Blog는 사용자 password를 제3자 application에 전달하지 않고 delegated authorization을 구현하는 OAuth 2.0의 역할과 흐름을 정리했습니다. OAuth 자체가 안전을 자동 보장하는 것은 아니므로 redirect URI, PKCE, scope와 token storage 구현이 핵심입니다.

- **중요한 이유:** agent와 외부 SaaS 연동에서도 장기 API key 공유보다 사용자 동의 기반의 짧은 수명 token과 최소 scope가 감사·폐기에 유리합니다.
- **발표일:** 2026-11-10 KST
- **원문:** [Stack Overflow Blog — Never Share Your Password Again](https://stackoverflow.blog/2026/11/09/never-share-your-password-again-the-oauth-2-0-solution/)

### agent의 대량 메일 발송을 제한하는 guardrail 공개 사례

`agent-email-guard` 프로젝트는 agent가 receipt 400건을 보내려 한 상황에서 발송을 5건으로 제한한 사례와 구현을 공개했습니다. 신규 공개 프로젝트의 주장인 만큼 production 적용 전 code review와 자체 재현이 필요하지만, side effect 도구에 별도 quota를 두는 패턴은 유효합니다.

- **중요한 이유:** 메일·환불·주문취소처럼 되돌리기 어려운 도구에는 batch ceiling, dry-run, 승인과 idempotency key를 model 밖에서 강제해야 합니다.
- **공개일:** 2026-11-10 KST
- **원문:** [agentisend/agent-email-guard](https://github.com/agentisend/agent-email-guard)

### DeepL, Cloud WAN maintenance 중 closest-exit routing 유지 사례 공개

AWS는 DeepL이 Cloud WAN 유지보수 동안에도 가장 가까운 egress를 유지하도록 routing을 구성한 사례를 공개했습니다. 단일 vendor 사례의 결과는 topology와 traffic에 따라 달라지지만, maintenance가 latency와 data residency에 미치는 영향을 함께 다룬 점이 실무적입니다.

- **중요한 이유:** multi-region API는 정상 상태 latency뿐 아니라 route withdrawal, failover convergence와 egress 비용을 정기적으로 검증해야 합니다.

## 개발자 체크포인트

- AI accelerator 도입은 model별 p95 latency·throughput뿐 아니라 compiler, quota, network와 data-egress 비용까지 비교하세요.
- agent가 dependency를 갱신할 때 lockfile, 허용 SemVer 범위, changelog와 regression test를 강제하세요.
- agent의 메일·환불·주문취소 도구에는 batch ceiling, idempotency key, dry-run과 사람 승인을 model 밖에서 적용하세요.
- OAuth·장기 token은 최소 scope, 안전한 저장, rotation·revoke와 tenant별 audit log를 점검하세요.
- Next.js 자동 압축과 결제 SDK preview는 proxy·checkout·webhook replay test를 통과한 뒤 production에 반영하세요.

## 웹·클라우드·인프라

### Linux 7.4 memblock, 선형 탐색을 이진 탐색으로 바꿔 극단적 부팅 지연 개선

Linux 7.4용 memblock 변경은 초기 부팅의 물리 메모리 allocator에서 range 탐색을 이진 탐색으로 바꿉니다. 패치 측정에서는 Kernel Handover처럼 메모리 영역이 심하게 조각난 최악 조건의 retrieval이 약 268초에서 50ms로 줄었으며, 일반 workload의 보편적 부팅 개선 수치는 아닙니다.

- **실무상 중요성:** 대규모·조각난 memory map이나 live-update/KHO를 쓰는 인프라는 후보 kernel에서 boot time과 memory-map correctness를 검증할 가치가 있습니다. 아직 Linux 7.4 merge 단계의 변경이므로 production backport 전에는 architecture별 회귀 시험이 필요합니다.
- **발표일:** 2026-10-24
- **원문:** [Phoronix — Linux's Early Boot-Time Physical Memory Allocator Sees Big Speed-Up](https://www.phoronix.com/news/Linux-7.4-memblock)

## 보안

### `Node2Shell` Brotli decoder 취약점, Python 패키지에도 영향 확인

GitHub 보안 권고는 Brotli decoder의 out-of-bounds write 취약점(CVE-2026-111497)이 PyPI `brotli`와 `brotlicffi`에도 영향을 준다고 확인했습니다. 조작된 Brotli stream으로 인접 상태 메모리 손상, 정보 노출, 서비스 거부와 잠재적 임의 코드 실행이 가능하며, `brotli` 1.0.3 이상 1.2.1 미만과 `brotlicffi` 1.0.3 이상 1.2.1.0 미만이 취약 범위입니다.

- **실무상 중요성:** Node.js만 고치고 끝내지 말고 Python service, proxy, crawler, image·document processor와 transitive dependency를 함께 조사하세요. `brotli` 1.2.1 또는 `brotlicffi` 1.2.1.0 이상으로 올리고 외부 압축 payload를 받는 경로를 우선 재배포해야 합니다.
- **권고 게시일:** 2026-10-22 (2026-10-23 갱신)
- **원문:** [GitHub Security Advisory GHSA-9v8h-qqgm-4m35](https://github.com/advisories/GHSA-9v8h-qqgm-4m35)

### GitHub, 새 npm 버전을 설치 전에 막는 package firewall 보도

GitHub의 npm package firewall이 방금 게시된 package version을 조직 환경에 설치하기 전에 차단할 수 있다는 기능 보도가 나왔습니다. 정확한 availability, 정책 기준과 예외 처리 방식은 GitHub의 최신 제품 문서와 조직 설정 화면을 기준으로 확인해야 합니다.

- **중요한 이유:** 새 version 직후의 공급망 공격에 대응할 시간을 벌 수 있지만 lockfile, provenance, dependency review와 registry 접근통제를 함께 써야 합니다.

### Rust crate backdoor가 드러내는 공급망 공격 경로 분석

보안 연구 글은 Rust crate에 악성 동작을 숨길 수 있는 여러 기법과 review가 놓치기 쉬운 지점을 설명했습니다. 이는 교육·방어 목적의 기술 분석이며, 특정 널리 쓰이는 crate가 실제 침해됐다는 공식 권고는 아닙니다.

- **중요한 이유:** memory-safe 언어도 build script, proc macro, dependency 교체와 release 계정 탈취 같은 공급망 위험까지 제거하지는 못합니다.
- **발표일:** 2026-10-28
- **원문:** [kerkour.com — Backdooring Rust crates for fun and profit](https://kerkour.com/rust-crate-backdoor)

### Notion, Linux용 공식 Flatpak 배포

Notion이 Linux 사용자를 위한 공식 Flatpak package repository를 공개했습니다. 설치 전 repository 서명, update channel과 조직의 sandbox·data handling 요구사항을 공식 안내에서 확인해야 합니다.

- **중요한 이유:** 비공식 wrapper 의존도를 낮출 수 있지만 Electron·Flatpak permission, 자동 update와 사내 SSO 호환성은 별도 검증이 필요합니다.
- **발표·확인일:** 2026-10-28
- **원문:** [Notion Linux Packages](https://app.linux-packages.notion.com/)

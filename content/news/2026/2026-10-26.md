## AI

### Cerebras, 3조 매개변수 모델의 wafer-scale 배치 구조 공개

Cerebras는 44GB 온칩 메모리를 가진 WSE-3T wafer 여러 장에 약 3조 매개변수 모델을 나누는 방식을 설명했습니다. 예시 모델은 선형 attention layer 두 개 또는 KV cache가 필요한 dense layer 한 개를 wafer 하나에 두고, layer 전체는 칩에 고정한 채 activation만 RDMA over Ethernet으로 전달하는 pipeline 구조입니다. 회사는 이 방식으로 다중 조 단위 모델을 초당 1,000~2,000개 이상의 token 속도로 실행할 수 있다고 주장하며, 실제 성능은 workload와 구성에 따라 달라질 수 있다고 명시했습니다.

- **실무상 중요성:** 대형 모델 serving을 비교할 때 단일 요청 속도만 보지 말고 동시 요청 수, context 길이에 따른 KV cache, 총 token throughput/전력과 fault domain을 함께 측정해야 합니다. 공개 수치는 공급사 설명이므로 자체 workload의 tail latency와 비용으로 검증해야 합니다.
- **발표일:** 2026-10-25
- **원문:** [Cerebras — How we deploy trillion-parameter frontier models](https://www.cerebras.ai/blog/how-we-deploy-trillion-parameter-frontier-models-on-cerebras)

### OpenAI·Anthropic 모델 가격 인하, cache read 비용이 agent 총비용을 좌우

데이터 과학자 Max Woolf는 최근 수개월의 가격표를 비교해 주요 모델 비용이 최대 80% 낮아졌고, coding agent에서는 cache read가 token 비용의 96~99%를 차지할 수 있다고 분석했습니다. 경쟁 모델과 다수 inference provider, serving 효율 개선이 가격 압력의 배경이라는 해석이며, 공급사의 공식 공동 발표나 향후 가격 보장은 아닙니다.

- **실무상 중요성:** 모델 선택표에는 입력·출력 단가뿐 아니라 cache read/write, 실제 cache hit rate와 task당 재시도 횟수를 넣어야 합니다. 할인에 맞춰 호출량을 자동 확대하기보다 주문·CS·개발 업무별 비용 상한과 품질 기준을 함께 두는 편이 안전합니다.
- **분석 게시일:** 2026-10-25
- **원문:** [Max Woolf — OpenAI and Anthropic cut their LLM prices by up to 80%](https://minimaxir.com/2026/10/cheap-llms/)

Zig main branch는 일부 연산자 조합의 우선순위를 더 이상 암묵적으로 정하지 않고 compiler가 괄호를 요구하도록 바꿨습니다. 2016년에 열린 proposal #114를 반영한 변경으로, Zig 자체 백만 줄 이상에서 353개 줄을 수정했으며 기존 0.17.x 평가 순서를 유지하는 자동 수정 도구도 안내합니다.

- **발표일:** 2026-10-24
- **원문:** [Zig Devlog — Partial Order Precedence](https://ziglang.org/devlog/2026/#2026-10-24)

### Cloudflare, 대용량 파일용 Origin Range Requests 전 요금제 공개

Cloudflare는 client가 요청한 byte 구간과 cache의 고정 chunk를 조합해 필요한 구간만 origin에서 가져오는 `Origin Range Requests`를 모든 요금제의 self-service 기능으로 공개했습니다. 회사 측 R2 측정에서는 p99 TTFB가 대략 절반으로 줄었고 후속 변경 후 유사 workload의 tiered-cache traffic이 주간 약 6% 감소했지만, 이는 Cloudflare 내부 workload 결과입니다.

- **실무상 중요성:** 영상, archive, AI model artifact를 제공하는 팀은 origin의 byte-range 지원과 stable ETag를 확인한 뒤 cache rule로 제한 적용할 수 있습니다. 부분 응답의 `206`, `Content-Range`, representation 변경과 압축 변환을 포함한 회귀 시험이 필요합니다.
- **발표일:** 2026-10-23
- **원문:** [Cloudflare — Origin Range Requests](https://blog.cloudflare.com/origin-range-requests/)

### Cloudflare, post-quantum GeoKey Manager closed beta 발표

Cloudflare는 복호화 key를 선택한 지역 안에서만 풀 수 있도록 ML-KEM-768과 고전 암호를 결합한 PQ GeoKey Manager를 closed beta로 공개했습니다. 지역 root key는 허가된 edge에만 공급되고 조건 불일치 시 fail-closed하며, 일반 제공은 2027년 1분기로 계획돼 있습니다.

- **실무상 중요성:** 금융·커머스처럼 data residency가 필요한 조직은 key의 지역 제한과 실제 traffic routing·inspection 위치가 서로 다른 통제임을 구분해야 합니다. GA 전에는 지원 지역, rotation, 장애 시 가용성, 감사 증적과 규제기관 인정 범위를 확인해야 합니다.
- **발표일:** 2026-10-23

### Amazon Bedrock AgentCore, Web Answer 기능 발표

AWS는 AgentCore에 웹 정보를 찾아 답변 생성에 활용하는 Web Answer 기능을 발표했습니다. 공급자 설명만으로 출처 품질이나 최신성이 자동 보장되는 것은 아니므로 허용 도메인, 인용과 실패 시 fallback을 애플리케이션 계층에서 설계해야 합니다.

- **중요한 이유:** 에이전트의 웹 검색을 관리형 구성요소로 옮길 수 있지만 prompt injection, 개인정보 전송과 근거 추적 통제가 더 중요해집니다.
- **발표일:** 2026-11-05
- **원문:** [AWS — Announcing Web Answer on Amazon Bedrock AgentCore](https://aws.amazon.com/about-aws/whats-new/2026/11/web-answer-amazon-bedrock/)

## 보안·플랫폼

### GitHub secret scanning, 탐지기 개선·SpaceX 파트너 패턴 추가

GitHub는 secret scanning 탐지기를 개선하고 SpaceX를 partner pattern 공급자로 추가했습니다. 새 탐지 결과가 곧 실제 유출을 뜻하지는 않으므로 조직은 alert triage와 키 폐기·재발급 절차를 함께 운영해야 합니다.

- **중요한 이유:** 저장소에 포함된 새 자격증명 형식을 더 빨리 찾을 수 있으며, 기존 저장소에서도 새 경고가 발생할 수 있습니다.
- **발표일:** 2026-11-05
- **원문:** [GitHub Changelog — Secret scanning upgrades detectors](https://github.blog/changelog/2026-11-05-secret-scanning-upgrades-detectors-adds-spacex-as-partner)

### AWS IAM Roles Anywhere, 인증서 폐기 자동 확인 지원

AWS는 IAM Roles Anywhere가 인증서 폐기 상태를 자동으로 확인하도록 지원 범위를 넓혔습니다. 운영자는 CA의 CRL 배포 주기와 가용성, 캐시 동작을 확인하고 폐기 시험을 runbook에 포함해야 합니다.

- **중요한 이유:** AWS 외부 workload가 사용하는 X.509 자격증명이 폐기된 뒤에도 유효하게 취급되는 시간을 줄일 수 있습니다.
- **발표일:** 2026-11-05
- **원문:** [AWS — IAM Roles Anywhere automatic certificate revocation checking](https://aws.amazon.com/about-aws/whats-new/2026/11/iam-roles-anywhere-cdp/)

## 데이터베이스·웹·클라우드·API

### Amazon DynamoDB, bulk put items 지원

AWS는 DynamoDB에 여러 항목을 대량 입력하는 bulk put 기능을 추가했습니다. 기존 BatchWriteItem과의 차이, 실패 항목 처리, 용량 소비와 재시도 계약을 SDK·API 문서에서 확인한 뒤 migration해야 합니다.

- **중요한 이유:** 초기 적재·이관·event backfill의 요청 수를 줄일 수 있지만 부분 실패와 idempotency를 잘못 다루면 중복·누락이 생길 수 있습니다.
- **발표일:** 2026-11-05
- **원문:** [AWS — Amazon DynamoDB now supports bulk put items](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-dynamodb-now-supports-bulk-put-items/)

### Amazon RDS for Oracle, 자체 관리 AD Kerberos 인증 지원

Amazon RDS for Oracle이 self-managed Active Directory를 이용한 Kerberos 인증을 지원합니다. trust, DNS, 시간 동기화와 장애 시 break-glass 계정까지 포함해 시험해야 하며 단순히 비밀번호 인증을 끄는 방식으로 전환해서는 안 됩니다.

- **중요한 이유:** 기업의 기존 identity 체계와 DB 인증을 연결해 장기 비밀번호 노출을 줄일 수 있습니다.
- **발표일:** 2026-11-05
- **원문:** [AWS — RDS for Oracle Kerberos with self-managed Active Directory](https://aws.amazon.com/about-aws/whats-new/2026/11/rds-oracle-kerberos-self-managed-ad/)

### AWS Systems Manager Parameter Store, 내장 데이터 타입으로 조직·검증 강화

AWS는 Parameter Store에 조직화와 값 검증을 위한 built-in data type 지원을 발표했습니다. 기존 자유 형식 parameter와의 호환성, validation 실패 동작과 IaC drift를 staging에서 먼저 확인해야 합니다.

- **중요한 이유:** 잘못된 endpoint·identifier가 배포 시점까지 전파되는 것을 줄이고 configuration contract를 명시할 수 있습니다.
- **발표일:** 2026-11-05
- **원문:** [AWS — Parameter Store built-in data types](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-ssm-parameter-store-allows-organization-validation-with-new-data-types/)

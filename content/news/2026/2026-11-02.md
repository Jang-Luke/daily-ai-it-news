### ChatGPT 공개 공유 링크만 열어도 계정 권한으로 동작할 수 있었던 취약점 공개

Parameter 연구팀은 ChatGPT의 HTML Preview sandbox와 graph가 불러오는 MathLive message listener를 조합해, 공개 대화 링크를 연 로그인 사용자의 session에서 공격자 JavaScript를 실행할 수 있었다고 밝혔습니다. 연구팀은 private conversation 열람과 외부 전송까지 검증했다고 주장하며, 피해자는 app 설치나 code 붙여넣기 없이 링크만 열면 됐다고 설명했습니다.

- **중요한 이유:** 서로 안전해 보이는 두 component가 `postMessage` origin 검증과 HTML 처리 경계에서 연결되면 sandbox를 우회할 수 있으므로, embedded preview와 third-party widget을 함께 위협 모델링해야 합니다.
- **발표일:** 2026-10-28(최근 72시간 내 공개 색인 재확인)
- **원문:** [Parameter — Do the Math: How We Took Over ChatGPT Accounts](https://www.parameter.ai/labs/we-found-a-gap-at-openai)

### Northflank, 모든 환경변수가 복호화됐다고 가정하고 즉시 교체하라고 권고

Northflank status 공지는 고객이 제공한 AI API key의 무단 사용 신고를 조사 중이며, 모든 environment variable이 노출됐다고 가정해 secret·credential을 즉시 폐기·재발급하라고 안내했습니다. 회사는 AI provider 사용량·청구 기록 점검, public add-on 접근 차단을 권고했고 Postgres·MongoDB secret rotation 기능을 활성화했지만 추가로 확정된 조사 결과는 아직 없다고 밝혔습니다.

- **중요한 이유:** CI/CD와 cloud workload secret은 한 key만 바꾸는 것으로 끝나지 않으므로 secret group, global secret, database credential과 파생 token을 함께 순환해야 합니다.
- **업데이트 확인일:** 2026-10-30
- **원문:** [Northflank Status — security incident and secret rotation guidance](https://status.northflank.com)

### 브라질 법원, AI 검토를 속이려 문서에 숨긴 prompt injection에 제재

JetStream Security가 소개한 브라질 노동법원 결정에 따르면 두 변호사는 흰색 글씨로 AI가 청구를 피상적으로 검토하도록 지시하는 문장을 소장에 숨겼습니다. 법원은 이를 사법 절차의 신뢰를 해치는 행위로 보고 청구액의 10%인 약 8만4천200헤알(보도 환산 약 1만6천달러)의 제재를 부과했으며, 법원의 Galileu AI가 숨은 내용을 탐지했다고 전했습니다.

- **중요한 이유:** 외부 PDF·문서를 LLM에 넣는 법무·금융·지원 시스템은 보이는 내용뿐 아니라 machine-readable layer를 untrusted input으로 취급하고 탐지·격리·감사해야 합니다.
- **공개 확인일:** 2026-11-01
- **원문:** [JetStream Security — A Court Just Fined Lawyers for Prompt Injection](https://jetstream.security/insights/brazilian-court-sanctions-prompt-injection-filing/)

- **중요한 이유:** multi-agent 성능 주장은 model 수보다 표본 크기, token budget, contamination, 재현 log와 실패 유형을 함께 봐야 합니다.

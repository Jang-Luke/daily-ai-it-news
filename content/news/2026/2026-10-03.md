# 2026-10-03 AI·IT 개발 뉴스

실행 시점 기준 최근 24시간의 공식 발표·릴리스 10개를 선정했습니다. GeekNews, Hacker News 등 커뮤니티는 발견 경로로만 활용했으며, 아래 내용은 연결된 공식 원문을 기준으로 확인했습니다.

## AI

### DeepSeek, 오픈소스 데스크톱 에이전트 하니스 공개 미리보기

DeepSeek가 문서·스프레드시트 분석, 코딩, 리서치와 예약 작업을 처리하는 `DeepSeek Harness`를 전 세계 공개 미리보기로 배포했습니다. macOS와 Windows 데스크톱 앱 및 웹 UI를 제공하며, Cordis의 “모든 것이 플러그인” 구조 위에서 도구·스킬·UI를 조합하거나 대화로 플러그인을 만들 수 있도록 소스도 공개했습니다.

- **실무상 중요성:** 범용 에이전트를 사내 업무에 붙이는 진입 장벽은 낮아지지만 파일·셸·예약 실행과 플러그인이 넓은 권한을 가질 수 있습니다. 주문·정산 환경에서는 격리된 작업공간, 플러그인 허용 목록, 비밀정보 주입 통제와 변경 작업의 사람 승인을 먼저 설계해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [DeepSeek — DeepSeek Harness](https://www.deepseek.com/en/harness/)

### Ai2, 과학 보고서용 오픈웨이트 모델 AstaBrief 8B 공개

Ai2는 검색된 문헌 발췌를 인용이 달린 보고서로 만드는 Qwen3-8B 기반 `AstaBrief 8B`와 학습 데이터, 로컬 PDF 워크플로를 공개했습니다. 제공자 측 전체 파이프라인 측정에서 Fast 모드는 보고서당 평균 51.1초로 Claude 기반 Thinking 모드의 178.5초보다 약 3.5배 빨랐지만, Ai2는 비교 평가 대부분이 2025년에 수행돼 현재 최상위 모델과 다시 비교하지 않았다고 명시했습니다.

- **실무상 중요성:** 미공개 연구나 민감한 사내 문서를 외부 API로 보내지 않고 인용형 요약을 운영할 수 있는 선택지입니다. 다만 인용 존재 여부와 주장-근거 일치 여부는 별도 평가해야 하며, 속도 수치는 자체 하드웨어·문서 분포에서 재현해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Ai2 — Open-sourcing AstaBrief](https://allenai.org/blog/astabrief)

## 개발 생태계

### Zig 0.17.0, 빌드 서버 프로토콜과 ELF 증분 컴파일 개선

Zig 0.17.0은 206명이 참여한 925개 커밋을 담았고, 빌드 시스템을 재작업해 구성 프로세스와 실행 프로세스를 분리하는 Build Server Protocol을 도입했습니다. 새 ELF 링커를 바탕으로 x86_64 Linux의 증분 컴파일을 폭넓게 사용할 수 있게 했으며 LLVM 22, glibc 2.44, Linux 7.2 헤더 등 도구 체인도 갱신했습니다.

- **실무상 중요성:** 빌드·표준 라이브러리·언어 문법 변경 범위가 큰 릴리스이므로 Zig 서비스와 Zig 기반 네이티브 의존성은 즉시 일괄 승격하기보다 고정 버전 CI에서 회귀를 확인해야 합니다. 릴리스 노트가 명시한 알려진 버그와 주요 회귀도 배포 전 확인할 필요가 있습니다.
- **발표일:** 2026-10-02
- **원문:** [Zig — 0.17.0 Release Notes](https://ziglang.org/download/0.17.0/release-notes.html)

## 웹·클라우드·인프라

### Supabase, Turso 인수로 에이전트용 데이터베이스 계층 확장

Supabase가 SQLite를 Rust로 다시 구현하고 단일 서버에서 수많은 데이터베이스를 필요할 때 적재·중지하는 플랫폼을 만든 Turso 인수를 발표했습니다. 기존 Supabase의 Postgres와 Turso의 SQLite 제품은 계속 운영하며, 작은 에이전트 작업은 파일처럼 저렴하게 데이터베이스를 만들고 성장한 앱은 프로덕션으로 이어지는 경험을 목표로 합니다.

- **실무상 중요성:** 에이전트·미리보기 환경별 데이터베이스를 격리하는 패턴이 쉬워질 수 있지만, 인수 발표만으로 양 제품의 호환성이나 마이그레이션 경로가 완성된 것은 아닙니다. 데이터 수명주기, 지역·백업·암호화, Postgres 전환 방식과 비용을 실제 통합 사양이 나온 뒤 검증해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Supabase — Supabase is acquiring Turso](https://supabase.com/blog/supabase-is-acquiring-turso)

### Amazon EKS, Kubernetes 1.37 지원 시작

AWS는 모든 EKS 제공 리전에서 신규 클러스터 생성과 기존 클러스터의 Kubernetes 1.37 업그레이드를 지원하고, EKS Distro 빌드도 공개했습니다. 1.37에서는 `metrics.k8s.io/v1`이 GA가 됐고 DRA 장치 taint·toleration이 GA로, 외부·객체 메트릭을 이용한 HPA scale-to-zero가 기본 활성화된 베타로 올라갔습니다.

- **실무상 중요성:** 유휴 워커를 0개 Pod까지 줄이는 비용 최적화와 GPU 같은 장치 스케줄링 제어가 강화됩니다. 주문 API처럼 콜드 스타트에 민감한 워크로드는 최소 복제본과 기동 시간을 부하 테스트하고, 업그레이드 전 EKS Cluster Insights와 애드온 호환성을 확인해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [AWS — Amazon EKS and EKS Distro support Kubernetes 1.37](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-eks-distro-kubernetes-version-1-37)

### Amazon Aurora DSQL, 조건부 행만 저장하는 부분 인덱스 지원

Aurora DSQL이 `CREATE INDEX`의 `WHERE` 조건에 맞는 행만 저장하는 부분 인덱스를 모든 제공 리전에서 지원합니다. AWS는 수년치 완료 주문 가운데 열린 주문처럼 작은 작업 집합만 인덱싱하면 인덱스 크기와 읽는 데이터를 줄여 쿼리 성능과 저장 비용을 개선할 수 있다고 설명했습니다.

- **실무상 중요성:** `status = 'OPEN'` 같은 고선택도 주문 조회에는 직접적인 최적화 수단이지만, 실제 쿼리 조건이 인덱스 조건에 포함돼야 사용됩니다. 배포 전 실행 계획을 확인하고 상태 분포 변화, 쓰기 비용, 완료 주문의 이력 조회 성능을 함께 측정해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [AWS — Aurora DSQL partial indexes](https://aws.amazon.com/about-aws/whats-new/2026/10/aurora-dsql-partial-indexes/)

## 보안

### Apple, macOS Full Disk Access에 더 명시적인 사용자 승인 예고

Apple은 일부 앱이 백업용으로 마련된 Full Disk Access를 사용해 파일, 메일, 메시지와 브라우징 기록까지 사용자가 충분히 이해하지 못한 채 노출할 수 있다고 지적했습니다. AI 에이전트의 자율성이 커질수록 위험이 커진다며, 앞으로 이 권한은 사용자의 매우 명시적인 동작으로만 허용되도록 추가 통제를 도입하겠다고 밝혔습니다.

- **실무상 중요성:** macOS 에이전트와 업무 자동화 앱은 광범위한 디스크 권한을 전제로 한 설계를 줄이고 필요한 파일을 사용자가 직접 선택하는 흐름으로 전환해야 합니다. 향후 OS 변경에 대비해 권한 거부·철회 상태를 테스트하고, 고객·주문 데이터 접근은 앱 자체에서도 최소 권한과 감사 로그를 적용해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Apple Developer — Updates to Full Disk Access in macOS](https://developer.apple.com/news/?id=p6zjojqw)

### Qubes OS 4.3.2, 누적 보안 업데이트와 Fedora 44 템플릿 제공

Qubes OS 4.3.2 안정판은 이전 릴리스 이후의 보안 업데이트와 버그 수정을 새 ISO에 통합하고 기본 Fedora 템플릿을 Fedora 44, `kernel-latest`를 Linux 7.2로 갱신했습니다. 4.3 사용자는 일반 업데이트로 동등한 상태가 되며, 이미 지원 종료된 4.2 사용자는 4.3으로 즉시 업그레이드하라는 안내입니다.

- **실무상 중요성:** 고위험 분석이나 비밀정보 작업을 VM으로 분리하는 개발 환경은 최신 설치 매체와 템플릿으로 기준 이미지를 갱신해야 합니다. 4.3 이전 백업에서 복원한 템플릿은 예전 저장소를 계속 볼 수 있는 알려진 문제가 있으므로 공식 보정 절차와 전체 백업을 먼저 적용해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Qubes OS — Qubes OS 4.3.2](https://www.qubes-os.org/news/2026/10/02/qubes-os-4-3-2-has-been-released/)

## 오픈소스

### Lightpanda 1.0, CORS 기본 적용하며 베타 종료

Zig로 만든 비그래픽 헤드리스 브라우저 Lightpanda가 1.0을 출시하고 프로덕션 준비 상태를 선언했습니다. 프로젝트 측 집계로 Web Platform Tests 하위 테스트 173만여 개를 통과하며, `fetch`와 `XMLHttpRequest`에 CORS를 기본 적용하고 교차 출처 리디렉션의 인증 제거, 사설망 차단 옵션과 최신 V8 등 보안 경계를 강화했습니다.

- **실무상 중요성:** Puppeteer·Playwright·Selenium·CDP와 MCP를 지원해 크롤링이나 웹 에이전트의 Chromium 대안이 될 수 있습니다. 다만 그래픽 렌더링을 하지 않고 CORS 테스트도 아직 전부 통과하지 않으므로, 결제 페이지 자동화는 실제 사이트 호환성·리디렉션·쿠키·사설망 차단을 별도로 검증하고 전용 세션에서 실행해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Lightpanda — Lightpanda 1.0](https://lightpanda.io/blog/posts/lightpanda-1-0)

## 커머스·주문·결제

### Apple, Wallet 패스 제작·검증 도구 Pass Designer 베타 공개

Apple이 탑승권, 입장권, 멤버십 카드 등을 템플릿에서 만들고 iPhone·Apple Watch 표시를 실시간 미리 보는 macOS용 Pass Designer 베타를 공개했습니다. 필수 키와 예상 밖 정의를 편집 중 검증하고, 이벤트·장소·항공편 정보를 담는 semantic tag 편집과 구형 형식용 구조 자동 생성도 지원합니다.

- **실무상 중요성:** 주문 픽업 패스, 멤버십과 티켓의 디자인·스키마 오류를 실제 발급 전에 줄일 수 있습니다. 도구는 패스 디자인을 돕는 것이므로 서명, 발급 API, 갱신·취소 알림, 바코드 재사용 방지와 주문 상태 동기화는 기존 백엔드 테스트를 계속 유지해야 합니다.
- **발표일:** 2026-10-02
- **원문:** [Apple Developer — Pass Designer](https://developer.apple.com/pass-designer/)

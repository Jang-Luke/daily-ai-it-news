# 2026-11-07 AI·IT 개발 뉴스

최근 24시간의 공식 발표와 공개 자료를 우선하고, 중요한 보안·오픈소스 소식은 72시간까지 확장했습니다. 같은 사건의 재보도는 합쳤으며 공급자 설명과 편집자 판단을 구분했습니다.

## AI Agent·개발 도구

### GitHub, Copilot impact dashboard에 Chat·VS Code agent 사용량 추가

GitHub는 Copilot impact dashboard의 Agent adoption 차트가 Copilot Chat과 VS Code Agents window를 포함해 총 9개 Copilot 경험의 참여도를 보여 주도록 확장했습니다. 이 지표는 사용량을 보여 주지만 생산성이나 코드 품질을 직접 입증하는 것은 아니므로 배포 빈도·리뷰 시간·결함률과 함께 해석해야 합니다.

- **중요한 이유:** 조직이 agent 도입률을 제품·IDE별로 나눠 보고 교육이나 라이선스 배치의 근거를 만들 수 있습니다.
- **발표일:** 2026-11-06
- **원문:** [GitHub Changelog — Copilot impact dashboard adds chat and VS Code agent usage](https://github.blog/changelog/2026-11-06-copilot-impact-dashboard-adds-chat-and-vs-code-agent-usage)

### Slack, agent와 팀의 코드 작업을 연결하는 Slack Code API 발표

Slack은 agent가 팀의 대화 맥락과 코드 작업을 한 채널에서 이어 가도록 설계한 Code API를 소개했습니다. 공개 소개만으로 권한 경계·감사 로그·지원 저장소가 모두 확인되는 것은 아니므로 실제 적용 전 API 계약과 앱 권한을 검토해야 합니다.

- **중요한 이유:** 코드 생성·리뷰 요청이 협업 채널로 들어오면 승인 흐름은 짧아질 수 있지만 민감한 저장소 정보가 대화 공간에 노출될 위험도 커집니다.
- **발표일:** 2026-11-06
- **원문:** [Slack — Introducing the Slack Code API](https://news.google.com/rss/articles/CBMiXEFVX3lxTE1zTWFHa0g5VGxBcjNuYzJjSjVORjlpTmltVmpubDJzZ25ZNzVOMEp6M2Z6YXRhRXE5anlGZ0tYZllBal9nY043bWoyeDgwY0hXSFJWSENhTlR2UXc1?oc=5)

### AWS Agent Registry, GovCloud US-West에서 정식 제공

AWS는 Bedrock AgentCore의 Agent Registry를 GovCloud US-West에 정식 출시했습니다. MCP server, tool, agent, skill과 사용자 정의 리소스를 중앙 catalog에 등록하고 승인 workflow와 검색·native MCP endpoint로 발견할 수 있다는 것이 공급자 설명입니다.

- **중요한 이유:** 규제 환경에서도 agent 도구의 발견성과 승인을 중앙화할 수 있지만 registry 등록이 각 도구의 안전성 검증을 대신하지는 않습니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — Agent Registry in AWS GovCloud US-West](https://aws.amazon.com/about-aws/whats-new/2026/11/aws-agent-registry-govcloud-us-west/)

## 보안·플랫폼

### AWS Security Hub, compute 자원의 SBOM inventory 제공

AWS Security Hub가 Amazon Inspector가 생성한 EC2 instance, ECR image와 Lambda function의 SBOM을 모아 조직 전체 package·version inventory를 보여 줍니다. package, account, region별 필터와 resource 상세의 설치 소프트웨어 확인을 지원한다고 AWS는 설명합니다.

- **중요한 이유:** 취약점 공지가 나왔을 때 영향 package가 어느 workload에 설치됐는지 찾는 시간을 줄일 수 있지만, Inspector가 보지 못하는 자산과 runtime dependency는 별도 보완이 필요합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — Security Hub SBOM inventory](https://aws.amazon.com/about-aws/whats-new/2026/11/security-hub-sbom-inventory/)

### OpenSSH 취약점 CVE-2026-123158, 공개 직후 악용 보도

Help Net Security는 OpenSSH 취약점 CVE-2026-123158이 공개 수 시간 뒤 실제 공격에 이용됐다고 보도했습니다. 영향 버전·운영체제별 backport와 수정 여부는 OpenSSH release note 및 각 배포판 보안 공지를 기준으로 확인해야 합니다.

- **중요한 이유:** SSH는 관리 plane의 핵심이므로 인터넷 노출 서버를 inventory하고 vendor patch, 접근 제어와 인증 로그 점검을 우선할 근거가 됩니다.
- **보도일:** 2026-11-06
- **원문:** [Help Net Security — OpenSSH flaw exploited in the wild](https://news.google.com/rss/articles/CBMikAFBVV95cUxNNnVRekR2aEdSY2N0QzJmZVVpZkd4dms4UkpPblUwNUFsRXBVZnppMndDZTdRWW56bHRMSExmZjJ3ckdxdHBseG9wd2duV3lZOUxoUmVLa2VnOHVUaVNrMzNVdkoxN1dqU0JVVFZiVl91SUFyOHAySmZOdjk4b0g1LW9rZU9LRDZwQUR3VVJpSDU?oc=5)

### GitHub Copilot usage metrics API, review 처리율·telemetry 공백 표시

GitHub는 repository-level usage report에 Copilot code review 의견 수와 addressed rate를 추가하고, 사용자별 telemetry 누락 및 최소 지원 버전 미달도 표시하도록 API를 확장했습니다. 두 공지는 같은 측정 체계 변경이므로 하나의 사건으로 묶었습니다.

## 데이터베이스·웹·클라우드·인프라

### Amazon Redshift SUPER, 개별 문자열 한도를 16MB로 확대

Redshift는 database parameter로 opt-in하면 SUPER data type 안의 개별 문자열을 종전 65,535 byte에서 최대 16MB까지 저장할 수 있게 했습니다. JSON·Parquet·text·CSV ingest와 ELT 과정에 적용되며 큰 문서의 사전 변환을 줄일 수 있습니다.

- **중요한 이유:** 반정형 데이터 적재가 단순해지지만 큰 값의 scan 비용, memory 사용과 downstream client 호환성을 benchmark해야 합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — Redshift expands SUPER strings to 16MB](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-redshift-expands-super-to-16-million-bytes/)

### AWS Glue Data Catalog, Iceberg REST federation의 catalog-vended credential 지원

Glue Data Catalog가 외부 Apache Iceberg REST catalog가 발급한 임시 credential을 이용해 승인된 S3 prefix의 table만 읽는 방식을 지원합니다. Athena, EMR, Redshift와 Glue에서 외부 catalog의 coarse-grained table grant를 활용할 수 있습니다.

- **중요한 이유:** 장기 IAM 권한 대신 범위가 제한된 임시 자격증명을 쓸 수 있지만 catalog 정책과 S3 정책의 교집합을 통합 시험해야 합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — Glue catalog-vended credentials for Iceberg](https://aws.amazon.com/about-aws/whats-new/2026/11/glue-catalog-vended-credentials-iceberg/)

### Amazon MSK Replicator, GovCloud 두 Region으로 확대

AWS는 MSK cluster 사이 또는 외부 Kafka에서 MSK Provisioned로 비동기 복제를 관리하는 MSK Replicator를 GovCloud US-East와 US-West에서 제공한다고 발표했습니다. 재해 복구와 지역 간 streaming 복제를 위한 관리형 선택지가 늘었습니다.

- **중요한 이유:** 복제 인프라 운영 부담은 줄지만 ordering, consumer offset, lag와 failover 시 중복 처리 계약은 애플리케이션에서 검증해야 합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — MSK Replicator in GovCloud](https://aws.amazon.com/about-aws/whats-new/2026/10/amazon-msk-replicator-additional-aws-regions)

### Amazon SES, 아시아·유럽·멕시코 6개 Region 추가

Amazon SES가 New Zealand, Melbourne, Taipei, Thailand, Mexico Central과 EU Spain Region으로 확대됐습니다. transaction email을 사용자와 가까운 Region 또는 데이터 위치 요구에 맞춰 운영할 선택지가 늘었습니다.

- **중요한 이유:** 주문·결제 알림의 지연과 데이터 residency 설계에 유리하지만 sandbox 해제, domain 인증, suppression list와 failover 설정은 Region별로 확인해야 합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — Amazon SES in six new Regions](https://aws.amazon.com/about-aws/whats-new/2026/11/amazon-simple-email-service-new-aws-regions/)

### AWS MediaConvert, AI Smart Subtitles를 native workflow로 통합

MediaConvert가 AWS Elemental Inference 기반 Smart Subtitles를 VOD transcoding·packaging workflow에 직접 통합했습니다. 영어·프랑스어·독일어·이탈리아어·포르투갈어·스페인어 음성을 자동 자막화한다고 AWS는 설명합니다.

- **중요한 이유:** 별도 transcription pipeline을 줄일 수 있지만 전문용어 정확도, 접근성 기준과 사람 검수 비용을 실제 콘텐츠로 평가해야 합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — MediaConvert Smart Subtitles integration](https://aws.amazon.com/about-aws/whats-new/2026/11/mediaconvert-elemental-smart-subtitles/)

### EC2 Capacity Blocks for ML, 비용 상각 표시 지원

AWS CUR 2.0과 Cost Explorer가 EC2 Capacity Blocks for ML의 선불 비용을 reservation 기간에 걸쳐 상각해 사용 instance와 미사용 capacity 비용으로 보여 줍니다. 기존처럼 구매일에 한 번에 표시되는 방식보다 팀·project별 GPU 비용 배분이 쉬워집니다.

- **중요한 이유:** AI workload의 실제 단위 비용과 idle capacity를 FinOps 지표에 반영할 수 있으나 회계 처리 기준과 내부 chargeback 규칙은 별도 합의가 필요합니다.
- **발표일:** 2026-11-06
- **원문:** [AWS — amortization for EC2 Capacity Blocks for ML](https://aws.amazon.com/about-aws/whats-new/2026/10/aws-ec2-capacity-blocks-ml/)

# 2026-11-12 AI·IT 개발 뉴스

최근 24시간의 공식 발표·릴리스와 공개 보도를 우선했으며, 맥락 보완에 필요한 경우 72시간까지 확장했습니다. 공급자 benchmark와 사례 수치는 게시자 주장으로 구분하고, 실제 도입 전 자체 workload·보안 경계에서 재검증할 지점을 함께 적었습니다.

## AI Agent·개발 도구

### AWS Emulator, 로컬에서 AWS API 호환 애플리케이션 테스트 지원

AWS는 일부 AWS 서비스 API를 개발자 PC에서 흉내 내는 무료 AWS Emulator를 공개했습니다. 네트워크 연결이나 실제 계정 비용 없이 빠른 개발·테스트가 가능하지만 production 서비스의 quota, IAM, 장애 모드와 완전히 같다고 가정해서는 안 됩니다.

- **중요한 이유:** 주문·결제처럼 외부 side effect가 큰 서비스는 로컬 에뮬레이터로 반복 테스트를 빠르게 하되 실제 AWS 통합·권한 테스트를 별도 단계로 유지해야 합니다.
- **발표일:** 2026-11-12 KST
- **원문:** [AWS — Test your applications against AWS locally with AWS Emulator](https://aws.amazon.com/blogs/aws/test-your-applications-against-aws-locally-with-aws-emulator/)

### Google CodeMender, pull request에서 취약점 수정 자동화 안내

Google Cloud는 CodeMender를 pull request workflow에 연결해 취약점을 찾는 데서 끝나지 않고 수정 제안과 검증까지 수행하는 방식을 공개했습니다. 자동 생성 patch도 사람의 review, 재현 가능한 test와 최소 권한 token 아래에서 다뤄야 하며, 보안 도구의 판단을 곧바로 production merge 승인으로 바꾸면 안 됩니다.

- **중요한 이유:** AI 기반 remediation은 대응 시간을 줄일 수 있지만 dependency update·API 변경이 만드는 기능 회귀와 공급망 위험을 CI에서 함께 검증해야 합니다.
- **발표일:** 2026-11-11 KST
- **원문:** [Google Cloud — How to run CodeMender in your pull requests](https://cloud.google.com/blog/products/identity-security/dont-just-flag-it-fix-it-how-to-run-codemender-in-your-pull-requests)

### GitHub 개인 계정에도 issue type·field 제공

GitHub는 개인 계정 소유 repository에서도 issue type과 field를 사용할 수 있게 했습니다. 조직 수준 process 없이도 bug, feature, task 같은 작업 종류와 구조화 필드를 관리할 수 있지만 기존 label·automation과 중복 규칙이 생기지 않도록 migration 기준을 정해야 합니다.

- **중요한 이유:** 소규모 프로젝트도 backlog schema를 명시하면 coding agent가 작업 범위·완료 조건을 더 안정적으로 읽을 수 있습니다.

## 보안·플랫폼

### Node.js 26.13.1·24.22.3·22.23.5 보안 릴리스

Node.js가 지원 중인 여러 release line에 HTTP/2, TLS, HTTP parser, permission model과 zlib 관련 보안 수정을 배포했습니다. 26.13.1 기준으로 원격 TLS server crash, mTLS session resumption과 SNI, pending write의 stream·buffer 수명 등 high severity 문제가 포함됩니다.

- **중요한 이유:** 인터넷에 노출된 API gateway와 checkout backend는 단순 runtime 교체뿐 아니라 HTTP/2·mTLS·proxy·long-lived stream 회귀 테스트 후 신속히 올려야 합니다.
- **발표일:** 2026-11-12 KST
- **원문:** [Node.js v26.13.1 security release](https://github.com/nodejs/node/releases/tag/v26.13.1) · [v24.22.3](https://github.com/nodejs/node/releases/tag/v24.22.3) · [v22.23.5](https://github.com/nodejs/node/releases/tag/v22.23.5)

AWS는 shared cache부터 tenant별 cache까지 ElastiCache multi-tenancy의 격리 선택지를 비교했습니다. 비용 효율만 보고 key prefix에 의존하면 noisy neighbor, eviction과 accidental cross-tenant access가 생길 수 있어 tenant tier와 규제 수준에 맞춘 경계가 필요합니다.

- **중요한 이유:** session·cart·rate-limit cache의 tenant key 규칙, quota, encryption과 장애 blast radius를 application contract로 고정해야 합니다.

### FastAPI 0.162.5, 취소 시 동기 dependency cleanup 수정

FastAPI 0.162.5는 request cancellation 때 synchronous dependency cleanup이 빠질 수 있는 문제를 수정했습니다. 내부적으로 `pydantic-ai` 대신 slim variant를 쓰는 변경도 포함되므로 lockfile과 cancellation test를 함께 확인해야 합니다.

### Vite 8.3.8, inline worker asset·CSS·Sass 성능 수정

Vite 8.3.8은 inline worker가 참조하는 asset emission, type-only import의 native loader 호환 검사, CSS entry 처리와 Sass import 성능을 수정했습니다. build tool patch라도 worker asset 누락과 output 차이가 production에서만 드러날 수 있습니다.

- **중요한 이유:** service worker·web worker를 쓰는 storefront는 chunk·asset manifest와 offline/cache 동작을 build artifact 기준으로 비교해야 합니다.

### Next.js 16.5 canary.47, image distortion·Turbopack 처리 개선

Next.js 16.5.0-canary.47은 intrinsic proportion을 이용한 image distortion 감지, build static worker CPU profile, Turbopack missing export 처리 등을 포함합니다. canary는 안정판이 아니므로 관련 증상 재현이나 사전 호환성 검증 목적에 한정하는 편이 안전합니다.

- **중요한 이유:** image layout과 bundler 변화는 상품 이미지 품질, Core Web Vitals와 build reproducibility에 직접 영향을 줄 수 있습니다.

### workerd 2026-11-11 릴리스, pooled connection·memory 계측 수정

Cloudflare `workerd` v1.20261111.1은 peer가 닫은 pooled connection의 request 재전송, queued WebSocket message의 isolate memory 반영, heap usage 응답과 SQLite CTE regression rollback 등을 포함합니다. 재전송은 read request에는 유용하지만 mutation endpoint의 idempotency가 불명확하면 중복 side effect를 만들 수 있습니다.

- **중요한 이유:** edge runtime upgrade 때 checkout·webhook의 idempotency key, WebSocket memory limit과 database query 회귀를 함께 점검해야 합니다.
- **발표일:** 2026-11-11 KST
- **원문:** [cloudflare/workerd v1.20261111.1](https://github.com/cloudflare/workerd/releases/tag/v1.20261111.1)
